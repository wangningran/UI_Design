# BTC 陷阱判定 / 价格位置系统

每天运行一次，判断当前 BTC 是熊市陷阱、牛市陷阱还是真突破，并给出价格位置评分和区间预测。

```bash
pip install pandas numpy scikit-learn
python3 fetch_data.py     # 从 Yahoo Finance 下载 BTC 和宏观日线到 data/
python3 analyze.py        # 特征、回测、模型 → out/results.json, out/charts.json
python3 build_report.py   # 生成 out/report.html
```

## 七层特征（engine.py）
| 层 | 内容 |
|---|---|
| L1 周期 | ATH 后天数、减半后天数、回撤、按 ATH 对齐的周期叠加 |
| L2 估值 | Mayer 倍数、价格/200 周均线、对数价格 4 年 z 分数 |
| L3 趋势 | 均线距离与斜率、周线 20 均线、周线高低点结构 |
| L4 动量 | 日/周 RSI、周 MACD 柱、ROC、波动率 |
| L5 K 线 | 55 日区间突破/跌破事件、影线、放量 z 分数 |
| L6 宏观 | DXY、10Y、3M、曲线、SPX、VIX、HYG、黄金、原油、USDJPY、BTC-SPX 相关性 → 宏观评分 |
| L7 资金 | ETH/BTC、MSTR/BTC（ETF 流量需手动补充） |

## 陷阱定义
- 跌破事件：收盘价跌破前 55 日最低价。60 天内收回到跌破位 +5% 以上，且在此之前没有再跌 10%，算**熊市陷阱**。
- 突破事件：收盘价突破前 55 日最高价。60 天内回落到突破位 −5% 以下，且在此之前没有再涨 10%，算**牛市陷阱**。

## 三个输出（analyze.py）
1. 陷阱概率：条件基准率，加上逻辑回归和梯度提升，按年份滚动做样本外验证。
2. 价格位置评分：估值 30%、趋势 25%、动量 15%、周期 15%、宏观 15%，各项做扩展窗口 z 分数，不使用未来数据。
3. 区间预测：kNN 相似历史状态，加上分状态的块状自助蒙特卡洛。

## 局限
完整周期只有 3 轮，周期项有过拟合风险。缺少链上数据、资金费率和未平仓合约。以上不构成投资建议。
